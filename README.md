## Domain

`purpur.berlin` liegt bei IONOS und zeigt per DNS auf GitHub Pages. **Pages ist
ausgeschaltet**, die Domain führt deshalb vorerst ins Leere. Zum Livegehen genügt
später ein Schalter: Settings → Pages → Branch `main`.
